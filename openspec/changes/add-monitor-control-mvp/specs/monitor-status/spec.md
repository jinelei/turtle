# Spec Delta

## Purpose

读取并展示显示器的运行状态与能力清单：常用 VCP 特征的当前值/最大值，以及解析 Capabilities 字符串得到的全部控制点，用于信息回显、输入源过滤与 DDC/CI 排错。

## ADDED Requirements

### Requirement: 读取常用 VCP 特征值

系统 SHALL 支持读取连续型（C）VCP 特征的当前值与最大值，首期至少覆盖亮度（0x10）、对比度（0x12）、音量（0x62）与当前输入源（0x60）；每个值 MUST 标注特征名称、当前值与取值范围。

#### Scenario: 查看显示器实时状态

- **WHEN** 用户打开某显示器的信息面板
- **THEN** 面板展示亮度（如 70/100）、对比度（如 80/100）、音量（如 30/100）及当前输入源

#### Scenario: 显示器不支持某特征

- **WHEN** 读取音量（0x62）返回"不支持该 VCP 码"
- **THEN** 音量行展示"不支持"，其他特征仍正常展示，面板不报错

### Requirement: 获取并解析 Capabilities 字符串

系统 SHALL 通过 VCP 0xF3 获取显示器 Capabilities 字符串并解析其协议版本、类型、型号与支持的 VCP 码表；解析失败时 MUST 保留原始字符串供查看，不得丢弃。

#### Scenario: 展示显示器全部控制点

- **WHEN** 用户查看"支持的功能"列表
- **THEN** 列表按名称展示该显示器声明支持的 VCP 控制点（如亮度、对比度、输入源选择、音量等），输入源选择区据此过滤

#### Scenario: Capabilities 字符串残缺

- **WHEN** 0xF3 返回的字符串被截断、括号不配对
- **THEN** 系统展示"能力信息不完整"提示与已解析出的部分，同时提供"查看原始字符串"入口

#### Scenario: 显示器不支持 VCP 0xF3

- **WHEN** 显示器（Lenovo P27h-20 实测即如此）不响应 0xF3，返回"不支持该 VCP 码"
- **THEN** 信息面板其余内容（身份信息、常用 VCP 读取）正常展示，控制点区域明确提示该显示器不支持 Capabilities，输入源候选回退到内置标准/厂商映射表，且不弹出错误

### Requirement: 状态刷新与只读安全

信息面板 SHALL 提供手动刷新；所有状态读取操作 MUST 为只读 VCP Get，不得因读取行为修改显示器任何状态；首期不提供亮度/音量等的远程写入（仅输入源可写）。

#### Scenario: 连续刷新不改变显示器状态

- **WHEN** 用户连续多次点击刷新读取亮度等特征
- **THEN** 显示器实际亮度、音量、输入源均不发生任何变化

#### Scenario: 读取超时

- **WHEN** 某次 VCP Get 在超时时间内无应答
- **THEN** 对应行展示"读取超时"，用户可单独重试该项，不影响其他行已读到的值
